# 원작 RE1 지도 화면의 동작 (Biohazard.exe, GOG 일본어판 + Classic REbirth 1.1.4)

대상 EXE: SHA256 `9fd220aa2e8f336629edb1545cd172a5229b6c73d57e3f900e91e17785e8aad8`, PE 타임스탬프 `0x3642d468`, SizeOfImage `0x990000`. 아래 주소는 모두 이 EXE의 VA입니다. 정적 분석(capstone) 결과이며, 런타임 확인 여부는 각 항목에 적었습니다.

## 지도 리소스

## 방 = CLUT 블록

- 한 TIM 안에서 방 슬롯 *k*는 팔레트 13+6k … 18+6k를 씁니다: +0 문 표시(노랑), +1/+2 세부선(진녹), +3/+4 바닥(녹), +5 검정. 팔레트 7은 공용 벽선(회색).
- 슬롯 번호 = 그 스테이지의 방 번호(RDT `ROOMsrrp`의 `rr`). 예외(카메라별 분할)는 `0x43ca60`에서 처리: 저택 07(카메라 3–6)→슬롯 0x1D, 0F(컷 3·4)→0x1E, 10(컷 0)→스테이지1 슬롯 0x1E, 0C(컷 4–7)→0x1F, 2층 0F(컷 2·5)→0x1D, 동굴 0B→0x11, 0F→0x12, 연구소 07(카메라 0–3)→0x16.
- 로더 `0x43bfb0`: 페이지 TIM을 `0xD5117C`에 읽고, 슬롯마다 방문 여부를 검사해 **미방문 방의 6색을 0(투명)**으로 바꾼 뒤 픽셀 중 CLUT 값이 0인 곳을 0으로 지웁니다. 같은 TIM을 두 번 올립니다: 슬롯 n=0xD(평상시), n=0xE(현재 방 +1..+3을 빨강 0x1F) — 현재 방 깜빡임은 이 두 장을 번갈아 씁니다(`0x43c330`).

## 방문 플래그

- 방문 비트: `Flg_ck(0xC387A0 /*Flg_7*/, base[stage] + slot)`, `base = 0x4b1bc8 = [0, 32, 63, 82, 100]`, 슬롯 수 `0x4b1bd0 = [32, 31, 19, 18, 24]`.
- 맵 스테이지 = `Stage_no % 5` (`0x43ca9a`). 따라서 저택 재방문(Stage_no 5·6, 폴더 Stage6/7)은 저택 페이지·플래그를 그대로 씁니다.

## 지도 상태 구조체 `0xB38DE0`

| 오프셋 | 의미 |
|---|---|
| +1 | 로드 단계(0 로드, 1 표시) |
| +3 | 열기 애니메이션 상태(0x43c3e9 점프 표) |
| +4 | 현재 보고 있는 지역(area) |
| +5 | 현재 맵 스테이지 |
| +6 | 현재 보고 있는 페이지 |
| +7 | 현재 방 슬롯 |
| +8..+B | 지역별 선택 층 |
| +0xC | 위/아래 층 이동 가능 표시 |
| +0xD | 갈 수 있는 지역 비트 |

초기화 `0x43ca60`(Stage_no·Room_no·Cut_no로 페이지와 슬롯 결정) → `0x43cd30`.

## 그리기

- 지도는 PSX `GsSPRITE` 세 장(`0x4b1d58`, `0x4b1d7c`, `0x4b1da0`, 36바이트)으로 그립니다. 열기 애니메이션이 끝나면 첫 장이 x=128, y=78, w=128, h=100, uv=(0,136), 회전 중심 m=(80,50), 배율 0x1000 → **TIM 픽셀 (px,py)는 화면 (48+px, 28+py)** (PSX 320×240 좌표, 정적 추정·런타임 미검증).
- 그리기 함수 `0x43c7c0`(→ `0x4422e0` GsSPRITE, `0x441920` Add_sprt). 텍스처 슬롯: `Add_sprt(sprt, z, n, count)`는 전역 슬롯 `n+15`(0x6977a8 + i*0x21c)부터 찾고, 호출 시점에 슬롯의 텍스처 포인터를 명령(+0x30)에 복사해 `0x47a9b0`으로 바로 제출합니다(`0x441d70..0x441de5`). 프레임당 명령 상한 300(`0x4b27f8` < 0x12c).

## 문 잠금

- 문 AOT `LockId`: bit7 잠금 가능, bit6 특수, 하위 6비트 = `Flg_2 (0xC38744)` 해제 비트. `LockType`: 0 없음, 0xFE 반대쪽 잠김, 0xFF 이벤트 잠금, 그 밖 = 필요한 아이템 ID. 판정 `0x455b40`, 해제 기록 `0x455c8b`(`0x414fc0` = 비트 켜기).

## 아이템 획득

- `item_aot_set` 처리 `0x418c00`: 데이터 +0x16(=GlobalId)으로 `Flg_ck(0xC3876C, id)`. **비트가 켜져 있으면 아이템이 남아 있는 것**입니다: 새 게임 초기화(`0x413f2f`..`0x413f61`)가 0..255번 비트를 켜고, 줍는 순간 `Flg_off 0x414fe0`(AND NOT)이 끕니다(`0x414280`, `0x418c52`, `0x42c910`). 문 해제는 반대로 `Flg_on 0x414fc0`(OR)이 켭니다(`0x455c8b`). 2026-10-19 Jill 세이브로 확인: 주운 산탄총(0)·잉크 리본(52)은 꺼짐, 남은 산탄총 탄약(2)은 켜짐.
- 메인 홀의 x=z=0, 16×16 아이템 AOT(산성탄, 락픽)는 배리가 건네주는 이벤트용이라 지도에서 뺍니다. 크기 0/1 AOT는 조사 이벤트로 주는 아이템이라 방 중심에 둡니다.
