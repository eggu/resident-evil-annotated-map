# HD-style map icons (RE1 HD set)

Copied unchanged on 2026-11-08 from the RE1 HD map mod (`re1-hd/resident-evil-hd-annotated-map/assets/icons/`; that project's sources page says its icons were generated with AI assistance in the item-icon style; the tool is not recorded). `map.json` maps RE1 (1996) item names to these files; basis `name` = the HD project names the item, `look` = matched by appearance only (verify in game), `badge` = HD flat category badge. Review 2026-11-08: the Lockpick wrongly showed a dagger because the Jill lockpick variant of a lock marker inherited the door key's icon (sword key art); it now has its own stem `lockpick` (`assets/hd-icons-new/lockpick.png`). Remaining 'look'-basis mappings that may be HD-only items and need an in-game check: Desk Key (44, the HD 'Old Key'), Doom Book 1/2 (91/90, HD books), Music Score (129, HD 'Missing Music' sheet), Battery (67, HD has a separate 'Battery Pack' 121), Square/Hexagonal Crank (61/60, which crank is which is a guess), Blue/Red Jewel (73/72) and Lighter (77) are likely fine. Items without an HD icon are listed in `docs/hd-icons-brief.md`; their new art goes in `assets/hd-icons-new/`.
