Annotated Map: Survivor's Notes 1.2.0
For Classic REbirth 1.1.3 or later (GOG Biohazard.exe).

Map overlay: room names, typewriters/item boxes, locked doors and their keys, key items, files/maps, puzzles, story events, common items, enemies.
Tab (or pad START): full-screen map. Map hotkeys: 0 all, 1 rooms, 2 locks, 3 key items, 4 files, 5 puzzles, 6 events,
7 common items, 8 enemies, 9 visible rooms (visited / revealed / all), \ English / Korean, H item names.
Settings: scripts/RE1.AnnotatedMap.ini (created on first run).
To change controls, close the game and edit [Keys] in that INI, then save and restart.
OpenKey=TAB: keyboard toggle. CloseKey=ESC: additional close key.
OpenPad=START: controller toggle, independent of the game's controller bindings.
If START is bound to a game action, use another unused button, e.g. OpenPad=LS (left-stick click).
Supported: A B X Y LB RB START BACK LS RS UP DOWN LEFT RIGHT, or NONE to disable it.
LT/RT triggers and button combinations are not supported. Add [Keys] if it is missing.
CloseOnCancel=1: close with the game's cancel action; use 0 to disable that action.
- / = (+): name size (50-150%). [ / ]: name opacity (10-100%). Shift + those keys: icon size / opacity.
Defaults: English, name size 100%, opacity 70%, Rooms on; other categories off.
